# Agent Guidelines & Rules

## Changelog Requirement
- Every time a change is made to the codebase, you MUST append a brief, human-readable summary of the changes to `changeslogs.txt` at the root of the project.
- **CRITICAL RULE:** Maintain only **ONE changelog version entry per day**. If you make multiple changes on the same day, combine them under a single version block for that day (e.g., `v:1.3.0 - 2026-08-20`). Do NOT create multiple version entries for the same date.
